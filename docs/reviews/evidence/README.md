# 运行证据

- `baseline`：原提交上的预期失败，确认回归测试能够识别原缺陷。日志仅移除了行尾空格。
- `full-suite`：30 个原测试入口、当时的 13 项审核回归和 7 个模型入口。
- `final-boundaries`：最终响应边界调整后，重跑公开网关、公开观察和全部 15 项审核回归。

每次 `run.json` 列出实际运行入口、返回值、环境和输入文件摘要。`generated/` 是运行后副本中的全部 JSON 快照，同时包含输入契约、历史报告和本次新生成报告。**只有 `run.json` 所列入口及其日志代表该次实际执行范围**；不能把复制进来的其他报告解释为本次重跑。完整重跑和最终边界重跑的源码差异列于 `summary.json`。

所有身份、密钥与数据为公开合成测试材料。源码改动需生成新的证据目录，不应手动重写已有运行摘要。
