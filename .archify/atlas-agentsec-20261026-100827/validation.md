## 重复总览检查

在仓库根目录启动仅监听本机的预览服务：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory .archify/atlas-agentsec-20261026-100827
```

在另一终端运行：

```sh
node .archify/atlas-agentsec-20261026-100827/check_atlas.mjs /path/to/pinned-archify http://127.0.0.1:8766/index.html
```

脚本使用上游的 Chrome 检查器，仅接受本机 HTTP 预览，保存检查结果与截图；可用 `ARCHIFY_CHROME` 指定浏览器。完成后关闭预览服务。此检查为一次浏览器冒烟测试，不替代六个原生 `finalize` 回执。
