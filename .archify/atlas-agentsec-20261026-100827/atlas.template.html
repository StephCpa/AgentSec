六个视图，一份可带走的图集

此 HTML 已内嵌六张 Archify 原生图，无需联网或安装依赖。只有打开 GitHub 源码链接时需要网络。下载当前图可得到独立 HTML。

图内切换「静态 / 动态」播放或暂停沿连线移动的信号；系统的“减少动态效果”设置会被尊重。节点支持点击、搜索、来源卡片、路径查看；也可切换主题、演示模式并导出图片或 SVG。动画表达逻辑流向，不是实测网络流量。

图集依据研究提交 2b596d4，包含未合并的研究增量。多个逻辑模块在同一 Python 对象中执行；数据流汇总不同参考配置，层次图按职责组织，生命周期跨越多张状态表。

这是合成数据参考原型。实际 LLM 边界、强制隔离、跨主机权威、完整安全证明、强基线、隐藏授权与 TEE/MPC 仍有待完成。图中的证据不能替代这些目标。
